# Cabaré da Leila · Imagens

Imagens usadas pelo site de guias da guilda Cabaré da Leila (Black Desert Online), servidas pela jsDelivr:

```
https://cdn.jsdelivr.net/gh/flipesantos34-cmd/cabaredaleilaguias-imagens@main/<pasta>/<arquivo>
```

- `skills/`: ícones de skills (gerados por `scripts/skills/gerar_catalogo.py` no repositório do site)
- `items/`: ícones de itens
- `images/`: imagens de fundo e dos temas
